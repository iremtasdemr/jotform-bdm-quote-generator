JOTFORM ENTERPRISE QUOTE GENERATOR — STANDALONE VERSION

This version uses only HTML, CSS, and JavaScript. It does not require React,
Next.js, Vercel, npm, or a build step.

To use it:
1. Keep index.html, quote-generator.css, quote-generator.js, and the assets folder together.
2. Double-click index.html, or serve this folder with any basic web server.
3. Complete the form and edit any PDF text directly in the preview if needed.
4. Select Download PDF. The PDF file is generated and downloaded directly.

The generated PDF filename is based on the company name.
